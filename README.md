# STAR MARKET

Статическая витрина Telegram Stars на GitHub Pages с серверной функцией Supabase для MyStars.

## Уже настроено
- Отдельный Supabase-проект `star-market` (не связан с `rivals-clash`).
- Edge Function `mystars`: серверный маршрут получения котировок MyStars в `ton` или `usdt_ton`.
- Сайт запрашивает котировки через Edge Function; демонстрационные цены в рублях удалены.
- Создание заказа у поставщика реализовано в серверной функции, но намеренно закрыто до настройки серверных секретов и явного включения.
- Оплата покупателей не подключена; функция не отправляет криптоплатежи и не отмечает заказ оплаченным или доставленным.

## Что нужно для активации MyStars
В Supabase Edge Function secrets необходимо добавить:
- `MYSTARS_API_KEY` — новый действующий ключ MyStars. Ключ хранится только на сервере.
- `ORDER_API_TOKEN` — длинный случайный секрет для защищённого вызова создания заказов.

Создание заказов остаётся отключённым, пока серверный секрет `MYSTARS_ORDERS_ENABLED` не установлен в `true`. Не добавляйте секреты в этот репозиторий, `index.html`, публичные переменные или сообщения. Старые ключи, которые ранее публиковались в переписке, следует отозвать/заменить.

## MyStars API
- Официальная документация: https://mystars.tg/docs
- Цены запрашиваются с `GET /v1/pricing/batch` с обязательным `payment_currency`.
- Перед созданием заказа сервер проверяет получателя через `POST /v1/recipients/check`.
- Создание заказа требует `Idempotency-Key` и создаёт заказ со статусом ожидания оплаты. Функция не отправляет платёж.
- Сайт пока не переводит себестоимость MyStars в розничную цену в рублях. Не используйте котировку в USDT/GRAM как цену для покупателя без отдельного расчёта.

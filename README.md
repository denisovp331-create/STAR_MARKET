# STAR MARKET

Статический сайт-витрина для ручной обработки заявок на Telegram Stars.

## Что есть
- Каталог пакетов: 50, 100, 250, 500 и 1000 Stars.
- Форма подготовки заявки с копированием текста.
- Адаптивная тёмная тема.

## Важно перед запуском
- Цены в каталоге демонстрационные. Проверь и замени их в `index.html`.
- Оплата не подключена.
- Заявки не отправляются на сервер и не сохраняются.
- Звёзды автоматически не выдаются; выполнение вручную.
- Добавь проверенный контакт поддержки перед запуском.
- Не проси у покупателей пароль, коды входа или QR-коды Telegram.

## Публикация через GitHub Pages
1. Открой Settings в репозитории.
2. Выбери Pages.
3. В Build and deployment выбери Source: Deploy from a branch.
4. Укажи Branch: main и Folder: /(root).
5. Нажми Save и дождись публикации.
